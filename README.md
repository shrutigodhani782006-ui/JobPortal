# 💼 JobPortal – ASP.NET Core MVC Web Application

A full-featured Job Portal web application built using ASP.NET Core MVC.  
This project allows job seekers to browse and apply for jobs while enabling recruiters to manage job listings efficiently.

---

## 🚀 Project Overview

JobPortal is a web-based application developed using ASP.NET Core MVC that connects job seekers and recruiters on a single platform. The system allows users to register, explore job listings, and apply for jobs, while recruiters can manage job postings and applications.

This project demonstrates strong understanding of MVC architecture, database integration, authentication, and CRUD operations.

---

## ✨ Features

### 👤 Job Seeker Features
- User Registration and Login
- Browse Available Jobs
- View Detailed Job Information
- Apply for Jobs
- Manage Profile

### 🏢 Recruiter / Admin Features
- Add New Job Listings
- Edit Job Details
- Delete Job Posts
- View Applications
- Manage Job Listings Dashboard

```

```

---

## 🗄️ Database Configuration

Make sure SQL Server is installed and running.

Update the connection string in `appsettings.json`:

```
"ConnectionStrings": {
  "DefaultConnection": "Server=YOUR_SERVER_NAME;Database=JobPortalDB;Trusted_Connection=True;TrustServerCertificate=True;"
}
```
